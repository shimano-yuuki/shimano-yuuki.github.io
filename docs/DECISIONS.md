## 2026-07 大物も 3D 化。シルエットは漆黒の帯の2種だけに

小魚に続いてサメ・クジラ・マンタ・クラゲも本人の要望で 3D にした。
断面リングの積層（サメ・クジラ）、キャンバー付き一枚翼（マンタ）、
半球 + 垂れ帯（クラゲ）をコードで生成。動きは種で違う——サメは横うねり、
クジラは水平の尾びれが縦に打ち、マンタは羽ばたきが翼端へ波及、
クラゲは傘が脈動して触手が遅れて揺れる。
大王イカとチョウチンアンコウは漆黒の帯に住み輪郭しか見えないため、
シルエット + 発光のまま残した（あの暗さでは 3D にしても違いが出ない）。

あわせて、スクロール中に生き物が上下へ跳ねる問題を直した。原因は
スクロール速度を位置に直接足していたこと。速度は捨て、なめらかに
補間される「深度」に結びつけた——潜れば帯の中心を過ぎた分だけ
静かに上へ流れていく（すれ違い）。ベールも CSS transition をやめ、
自前の指数追従にした（スマホの慣性スクロールで暗さが波打っていた）。

## 2026-07 近景の小魚だけ 3D 化。遠景はシルエット継続

当初 3D は「中途半端だと安く見える」ため見送ったが、本人の要望で再検討。
外部モデルを使わず、コード生成の 3D メッシュ（紡錘形の胴 + 尾びれ + 背びれ、
カウンターシェーディング + リムライト）で群れの小魚だけを 3D にした。
回頭は縦軸回転なので正面・背面の見付きが本当に変わり、旋回でバンクする。
クジラなどの大物は霞の中の影 = シルエットのまま。遠景が平板なのは
物理的にも正しく、大物まで 3D にする莫大な作り込みを避けられる。
同時に気泡を廃止（水槽っぽく見えるため）。マリンスノーは残した。

## 2026-07 渦の軌道は閉じさせる

攪拌点の角速度が無理数比だと軌道が閉じず、渦が形を崩して流れ去って見える。
全攪拌点の速さを基本角速度（周期 90 秒）の整数倍にし、軌道内の倍率も
整数（2, 3）にして同じ周回を繰り返すようにした。濃度も注入と減衰を
釣り合わせ（dissipation 0.3）、模様が飽和して潰れないようにした。

## 2026-07 泳ぎはシルエット + うねり + Boids。3D モデルは見送り

魚を「本当に泳いでいる」ようにする方法を検討した結果:

- 採用: UV 歪みの進行波（尾ほど振れる）+ Boids（分離・整列・結合 + 回遊目標 +
  カーソル逃避）。シルエットの美学のまま、泳ぎの説得力だけを上げられる
- 見送り: GLTF による 3D モデル化。**中途半端な 3D はシルエットより安く見える。**
  モデリング・ライティング・テクスチャ全部が高水準でないと成立せず、
  モデル調達（ライセンス）の問題もある。やるなら覚悟が要る

## 2026-07 ホスティングは GitHub Pages（無料枠は問題にならない）

- 公開リポジトリは Actions 分数無制限。push で無料枠は消費しない
- サイト 8.6MB（上限 1GB）、転送 100GB/月で個人サイトには余裕
- 代償として静的書き出し限定になり、次の制約を受け入れた:
  画像最適化なし / OG 画像はファイル規約でなく `npm run og` で実ファイル生成 /
  `/feed.xml` へのリンクは `<a>`（`<Link>` は RSC 先読みが 404 になる）

## 2026-07 可読性は実測主義。小ラベルだけ基準を緩める

- 「読める気がする」を禁止し、描画画素からコントラスト比を実測する方式にした
  （CSS の色文字列は Tailwind v4 の color-mix(oklab) が原因で解析できない）
- 本文 7:1 / 大きい文字 4.5:1。**11px の小ラベルのみ 4.5〜7:1 を許容**
  — 7:1 まで上げると本文と同じ明度になり階層が消えるため。意図的な妥協
- 本文の背後はベール（黒い膜）で水を落とす。演出を消すのではなく、
  読む場所だけ静かにする
