# DESIGN — 意匠の source of truth

見た目に関する判断はここが正。コードと食い違ったらコードを直す。

## コンセプト

**作品が静かに巡る、シンプルで奥行きのあるポートフォリオ。** 参照は mofu-dev.com
（制作開始時の原点）。最上段は名前のヘッダーで、背景にシアンの光の
静的な一枚絵を敷く。その直下に作品のスライドショー（three.js）を置き、
一枚絵が数秒ごとに、にじむような遷移で次の作品へ移り変わる。絵を押すと
その作品の詳細ページへ飛ぶ。主役は演出ではなく作品そのもの。
絵はこの2枚（ヘッダーの背景画とスライドショー）だけで、文字組みの側は
tndhjm 型ミニマルを引き続き飾らない。
目指すのは「見ていて落ち着く」で、賑やかさではない。

## 配色

| トークン | 値 | 用途 |
|---|---|---|
| `bg` | `#000000` | 地。純黒。スライドの絵とキャプションはこの上に載る |
| `fg` | `#f2f1e8` | クリーム白 |
| `fg-muted` / `fg-faint` | `#b9b7ac` / `#a8a69b` | 減衰2段 |
| `line` | `#22252b` | 罫。**作品表の行区切りにだけ**使う |
| `cyan` | `#8fd8e0` | 差し色。リンク下線・ホバー・ステータス行・スライド番号のみ |

スライドの絵の中の色（深い地と一点の光）は WebGL / canvas の中だけの色。
DOM 側には持ち込まない。

## 作品スライドショー（WebGL）の決まり

- 置き場所はトップのヘッダー（名前・自己紹介）の直下だけ。全幅・高さ 56svh。
  他ページには置かない
- 絵はまだ実物がないので、サンプル作品画をその場で生成する
  （`src/components/home/slideArt.ts`）。slug から決まる配色の抽象画に、
  作品名・SAMPLE の印・アプリ画面のモックアップを重ね、
  「作品の紹介スライド」として読めるようにする。frontmatter の `cover` に
  パスを書けば、そのスライドだけ実画像に差し替わる
- スライドは cover で切り出されるため、確実に見えるのは中央の
  x: 0.25〜0.75 / y: 0.25〜0.75。文字とモックアップはこの帯に収める
- 遷移は「ノイズで縁がにじむクロスフェード + わずかな変位」1種類。1.3 秒。
  待機中はごくゆっくり漂う（ケンバーンズ相当）だけで、色や形は動かさない
- 自動送りは 6 秒。ホバー・フォーカス・タブ非表示で止まる
- **文字を絵の上に載せない**。キャプション（番号・作品名・年）は絵の下の
  黒地に置く。絵の中の明るさはコントラスト実測で保証できないため
- 絵を押すとその作品の詳細へ。番号ボタンで手動切り替えもできる
- `prefers-reduced-motion`: 自動送りなし・漂いなし・切り替えは瞬時。
  WebGL 不可: 同じ配色の CSS グラデーション。導線・キャプションは DOM
  なので、絵が一切描けなくても内容はすべて読める

## ヘッダーの背景画の決まり

- トップのヘッダーだけに敷く。canvas 2D の静的な一枚絵（動かない）
- 光はシアン（`cyan` と同系）で右上に寄せ、名前と自己紹介の載る左と下は
  絵の側で黒へ落とす（`slideArt.drawHeaderArt`）。文字の可読性は実測で確認
- 名前は `display` の text-4xl〜6xl まで。10vw 級の巨大タイポは引き続き禁止

## 組版

- 本文・見出しとも Noto Sans JP。日本語主体、英語は固有名詞と名前だけ
- `display`（Archivo 太字）は名前などごく少数の英字に限定
- `label`（JetBrains Mono 小）は日付・年・技術名・ステータス行に
- 表の項目名は 作品名 / 年 / 担当 / 技術。数えは「件」
- **大文字トラッキングの英語ラベルを乱発しない。巨大タイポ（10vw 級）禁止**

## 装飾の上限（DOM 側）

- 罫線は 1px の横罫だけ。二重罫・枠箱・通し番号・sticky の飾りは使わない
- 演出は `FadeIn`（そっと現れる）1種類と、ステータス行の時計だけ
- ホバーは「色が cyan になる」程度。動かさない
- 動きを足したくなったら、それはスライドショーの WebGL の仕事かを先に疑う

## 可読性の基準（実測必須）

- 本文（16px 以上）7:1 / 大きい文字 4.5:1
- 12〜14px の添字（`label`・日付・タグ・表の担当欄）は **4.5〜7:1 を許容**。
  faint の階層色は素の背景でも 7:1 に届かない設計で、7:1 まで上げると
  本文と明度が並んで階層が消える（DECISIONS 2026-07 の判断を継続）
- 計測は `scripts/verify/contrast.mjs`（描画画素で測る。文字は絵の上に
  載せない決まりなので、測るのは黒地の上の文字だけでよい）
- `prefers-reduced-motion`: FadeIn は即表示、時計と静止したスライド以外に動くものはない
