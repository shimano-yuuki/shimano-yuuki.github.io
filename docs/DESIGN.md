# DESIGN — 意匠の source of truth

見た目に関する判断はここが正。コードと食い違ったらコードを直す。

## コンセプト

**作品が静かに巡る、シンプルで奥行きのあるポートフォリオ。** 参照は mofu-dev.com
（制作開始時の原点）。地は白、文字は黒、青が差し色。
トップは固定背景（fixed の canvas）に青が絹のように流れ、スクロールしても
背景は画面に残って文字だけが流れていく。初期表示は背景が1画面を覆い、
下へスクロールすると作品のスライドショー（three.js）が現れる。
一枚絵が数秒ごとに、にじむような遷移で次の作品へ移り変わり、絵を押すと
その作品の詳細ページへ飛ぶ。主役は演出ではなく作品そのもの。
絵はこの2つ（固定背景とスライドショー）だけで、文字組みの側は
tndhjm 型ミニマルを引き続き飾らない。
目指すのは「見ていて落ち着く」で、賑やかさではない。

## 配色

| トークン | 値 | 用途 |
|---|---|---|
| `bg` | `#ffffff` | 地。白。固定背景の青い流れはこの上に描かれる |
| `fg` | `#10151d` | 文字。黒 |
| `fg-muted` / `fg-faint` | `#333c47` / `#454e59` | 減衰2段 |
| `line` | `#e2e7ed` | 罫。**作品表の行区切りにだけ**使う |
| `accent` | `#1e40af` | 差し色。青。リンク下線・ホバー・ステータス行・スライド番号のみ |

固定背景の青（白〜 `#6ea6dc`）と、スライドの絵の中の色（深い地と一点の光）は
WebGL / canvas の中だけの色。DOM 側には持ち込まない。

## 作品スライドショー（WebGL）の決まり

- 置き場所はトップのヘッダー（名前・自己紹介）の直下だけ。
  誌面（measure）の幅に収め、端まで広げない。高さ 56svh
- **絵は contain ではめる**。渡された画像の寸法を切り抜かず全部見せ、
  余った部分は誌面と同じ白で埋める（本人の要望。cover 切り抜きは廃止）
- 実画像が無い作品は、サンプル作品画をその場で生成する
  （`src/components/home/slideArt.ts`）。slug から決まる配色の抽象画に、
  作品名・SAMPLE の印・アプリ画面のモックアップを重ね、
  「作品の紹介スライド」として読めるようにする。frontmatter の `cover` に
  パスを書けば、そのスライドだけ実画像に差し替わる
- 遷移は「ノイズで縁がにじむクロスフェード + わずかな変位」1種類。2.2 秒。
  待機中は静止（漂い・ズームは持たない）
- 自動送りは 4 秒。ホバー・フォーカス・タブ非表示で止まる
- **文字を絵の上に載せない**。キャプション（番号・作品名・年）は絵の下に
  置く。絵の中の明るさはコントラスト実測で保証できないため
- 絵を押すとその作品の詳細へ。番号ボタンで手動切り替えもできる
- `prefers-reduced-motion`: 自動送りなし・漂いなし・切り替えは瞬時。
  WebGL 不可: 同じ配色の CSS グラデーション。導線・キャプションは DOM
  なので、絵が一切描けなくても内容はすべて読める

## 固定背景（青い流れ）の決まり

- **全ページに敷く**（layout の `FlowBackground`）。canvas は
  **position: fixed**。スクロールしても絵は画面に残り、
  文字とスライドショーだけが上を流れていく
- three.js のシェーダー（`FlowScene.ts`）で、白い地に青が絹のように
  流れる場を描く（二段ドメインワープの fbm）
- 初期表示は背景が1画面を覆い尽くす（ヒーローが min-h 100svh。ナビは
  relative z-10 で背景の上に重なる）。スライドショーはスクロールして現れる
- 動きは「ゆっくり流れる・粒が明滅する」だけ。**ポインタには反応しない**
  （視差も追従もなし。本人の要望で撤去）
- 青は右上に寄せる。いちばん濃い芯は `#3d7ec2` 相当で、右上の帯にだけ許す。
  文字の多い左・下・最上部（ナビ）はシェーダー側で白へ戻し、
  可読性は必ず実測で確認する（濃くしたら必ず contrast.mjs を回す）
- `prefers-reduced-motion`: 静止した1フレームだけ描く。
  WebGL 不可: canvas 2D の静止画（`slideArt.drawHeaderArt`）に落とす
- 名前は `display` の text-4xl〜6xl まで。10vw 級の巨大タイポは引き続き禁止

## 組版

- 本文・見出しとも Noto Sans JP。日本語主体、英語は固有名詞と名前だけ
- `display`（Archivo 太字）は名前などごく少数の英字に限定
- `label`（JetBrains Mono 小）は日付・年・技術名・ステータス行に
- 表の項目名は 作品名 / 年 / 担当 / 技術。数えは「件」
- **大文字トラッキングの英語ラベルを乱発しない。巨大タイポ（10vw 級）禁止**

## 装飾の上限（DOM 側）

- 罫線は 1px の横罫だけ。二重罫・枠箱・通し番号・sticky の飾りは使わない
- 演出は `FadeIn`（そっと現れる）1種類と、ステータス行の時計だけ
- ホバーは「色が accent（青）になる」程度。動かさない
- 動きを足したくなったら、それはスライドショーの WebGL の仕事かを先に疑う

## 可読性の基準（実測必須）

- 本文（16px 以上）7:1 / 大きい文字 4.5:1
- 12〜14px の添字（`label`・日付・タグ・表の担当欄）は **4.5〜7:1 を許容**。
  faint の階層色は素の背景でも 7:1 に届かない設計で、7:1 まで上げると
  本文と明度が並んで階層が消える（DECISIONS 2026-07 の判断を継続）
- 計測は `scripts/verify/contrast.mjs`（描画画素で測る。文字は絵の上に
  載せない決まりなので、測るのは黒地の上の文字だけでよい）
- `prefers-reduced-motion`: FadeIn は即表示、時計と静止したスライド以外に動くものはない
