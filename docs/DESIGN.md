# DESIGN — 意匠の source of truth

見た目に関する判断はここが正。コードと食い違ったらコードを直す。

## コンセプト

**サイト全体が1本の水柱。スクロールが潜水。**
最上部は陽の差す水面、最下部（About）は真っ暗な深海。
works / blog / about はそれぞれ固有の深度帯に住んでいて、
ページを移っても水は途切れず、深度だけが移り変わる。

## 配色

色は「水」が持つ。UI は無彩色で、水の色に浮かぶ。

| トークン | 値 | 用途 |
|---|---|---|
| `--color-fg` | `#ffffff` | 見出し・強調 |
| `--color-fg-muted` | `#b0b0b0` | 本文・説明 |
| `--color-fg-faint` | `#a0a0a0` | 小ラベル（これ未満に暗くしない） |
| `--color-line` | `#2b2b2b` | 罫線 |
| `--color-line-bright` | `#454545` | 強めの罫線 |

水の色は `src/lib/depth.ts` の `WATER_RAMP`（深度 → 暗部色・明部色）が持つ。
UI に色を足したくなったら、まず水のランプから導出できないか考える。

## 書体

| 用途 | フォント | 使い方 |
|---|---|---|
| 欧文見出し | Archivo 800 | `display`。行間 0.86、字間 -0.035em。大きく詰める |
| 中見出し | Archivo 600 | `display-soft` |

## 可読性の基準（実測必須）

- **本文: 7:1 以上。大きい文字（18px 以上 / 14px 太字以上）: 4.5:1 以上**
- 11px の小ラベルのみ 4.5〜7:1 を許容する。7:1 まで上げると本文と同じ明度になり
  階層が消えるため。意図的な妥協であり、これ以上は下げない
- クジラや発光生物がラベルの真後ろを横切る瞬間の一過性の低下は許容する
  （数秒で回復する。本文が下回ることは許容しない）
- 計測は `scripts/verify/contrast.mjs`。CSS の色文字列ではなく描画画素で測る
- 可読性の仕掛け:
  - **ベール** — 本文の背後で水を落とす膜（`ContentVeil`）。最濃で水は 14% 残る
  - 光条はベールでは消えないので、シェーダー側でも `uVeil` で減光する
  - 生き物は読む列（画面中央帯）から斥力で遠ざける

## モーション

- イージングは `--ease-out-expo` / `--ease-in-out-quart` のみ
- ホバーは「明度が上がる + わずかに動く」。色相は変えない
- `prefers-reduced-motion`: 水は1フレーム描いて静止、生き物は止まる、
  出現アニメは即時表示。**内容はすべて読めること**
- WebGL 非対応: 深度連動のグラデーションに落ちる（`OceanFallback`）

## 生き物

- **近景の小魚は 3D、遠景の大物はシルエット。** 群れの小魚はコード生成の
  3D メッシュ（回頭で見付きが変わり、旋回でバンクする）。クジラ・サメなどの
  大物は霞の中の影 = シルエットのまま。遠景が平板なのは物理的にも正しく、
  中途半端な 3D の安っぽさを避けられる（`docs/DECISIONS.md` 参照）
- 外部モデル・外部画像は使わない。シルエットは `creatures.ts` のパス、
  3D 魚は `BoidsFlock.ts` の `buildFishGeometry`
- 泳ぎ = 進行波のうねり（尾ほど振れる）+ Boids（群れ）
- ベールの下では黒い影が沈むので、水の明部より明るい側へ寄せて
  「暗い水の中でうっすら光を返す影」にする。発光する種（アンコウ・クラゲ）は
  自分の光が体に映る
