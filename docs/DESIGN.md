# DESIGN — 意匠の source of truth

見た目に関する判断はここが正。コードと食い違ったらコードを直す。

## コンセプト

**削ることがエンジニアらしさ。** 参照は https://www.tndhjm.com/ 。
黒地・クリーム白・装飾ゼロで、情報（作品の表）が主役。
色は「ヒーローの色面1枚」にだけ大胆に使い、それ以外は無彩色で通す。
JS も最小（Next.js 静的書き出し + Tailwind + Markdown のみ）。速さも装いの一部。

## 配色

| トークン | 値 | 用途 |
|---|---|---|
| `bg` | `#0b0d10` | 地。わずかに青みの黒 |
| `fg` | `#f2f1e8` | クリーム白。参照サイトの温度感 |
| `fg-muted` / `fg-faint` | `#b9b7ac` / `#8e8c82` | 減衰2段 |
| `line` | `#22252b` | 罫。**作品表の行区切りにだけ**使う |
| `plate` / `plate-deep` | `#0e5a78` / `#071c2c` | 海から残した青。ヒーローの色面だけ |
| `cyan` | `#8fd8e0` | 差し色。等深線・リンク下線・ホバーのみ |

## 組版

- 本文・見出しとも Noto Sans JP。日本語主体、英語は固有名詞と名前だけ
- `display`（Archivo 太字）は名前などごく少数の英字に限定
- `label`（JetBrains Mono 小）は日付・年・技術名・ステータス行に
- **大文字トラッキングの英語ラベルを乱発しない。巨大タイポ（10vw 級）禁止**

## 装飾の上限

- 罫線は 1px の横罫だけ。二重罫・枠箱・通し番号・sticky の飾りは使わない
- 演出は `FadeIn`（そっと現れる）1種類と、ステータス行の時計だけ
- ホバーは「色が cyan になる」程度。動かさない
- 遊びの予算は「色面プレートの等深線」と「STATUS : WORKING」で使い切っている

## 可読性の基準（実測必須）

- 本文 7:1 / 大きい文字 4.5:1。クリーム白 on 黒なので余裕を持って満たすこと
- 計測は `scripts/verify/contrast.mjs`（描画画素で測る）
- `prefers-reduced-motion`: FadeIn は即表示、時計以外に動くものはない
