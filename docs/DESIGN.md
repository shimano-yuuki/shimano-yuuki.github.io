# DESIGN — 意匠の source of truth

見た目に関する判断はここが正。コードと食い違ったらコードを直す。

## コンセプト

**水槽の前で読む、静かなポートフォリオ。** 参照は webdesignclip.com の
3D/WebGL 系サイト群 + ネイチャーアクアリウム（水草水槽）。
three.js の水槽——青い水、緑の水草、熱帯魚 10 種——を背景に置き、
その上に情報（作品の表・記録）をクリーム白の文字で載せる。
md 以上では全画面の背景として右側に水を寄せ、文字の載る左は完全な黒。
md 未満（スマホ）では右下に固定した小さな水槽になり、ページの背景は黒のまま。
最初の1画面はヒーローの色面を敷かず、水槽そのものを見せる。
装飾の主役は背景の水槽ただ1つ。文字組みの側は引き続き飾らない。
目指すのは「見ていて落ち着く」で、賑やかさではない。

## 配色

| トークン | 値 | 用途 |
|---|---|---|
| `bg` | `#0b0d10` | 地。わずかに青みの黒。WebGL 不可のときの背景 |
| `fg` | `#f2f1e8` | クリーム白 |
| `fg-muted` / `fg-faint` | `#b9b7ac` / `#a8a69b` | 減衰2段 |
| `line` | `#22252b` | 罫。**作品表の行区切りにだけ**使う |
| `cyan` | `#8fd8e0` | 差し色（水明かりのシアン）。リンク下線・ホバー・ステータス行のみ |

水草の緑、魚の赤や琥珀は WebGL の中だけの色。DOM 側には持ち込まない。

## 背景の水槽（WebGL）の決まり

- 層は奥から: 水（光条 + カースティクス）→ 奥の水草 → 魚 → 手前の水草 → 気泡
- 水は青、水草は緑。それが水槽の自然な見え方
- 住人は 10 種（`AquariumScene.ts` の SPECIES が正）。カージナル・ラミーノーズ・
  エンバー・ブラックネオン・グローライト・スマトラ・ハニードワーフグラミー・
  エンゼルのペア・底のコリドラス・水面近くのハチェット。泳層と速さで立体感を出す
- 魚・水草は外部モデル・外部画像なし。すべてコード生成（`src/components/webgl/`）
- **水の明るさはシェーダー側で上限を抑える**。本文 7:1 を割る明るさは出さない
- 水明かり・水草・気泡・魚の生活圏はすべて右へ寄せ、文字の載る左は
  完全な黒（`bg` と同じ闇）に保つ
- 魚は画面中央の帯（読む列）から柔らかく押し返される。文字の真後ろを群れが
  通り続けないための規則
- 水草は右の袖に植え、本文の通り道は空ける
- md 未満はタンク表示: キャンバスが右下の小窓（`line` の 1px 枠）になり、
  小窓の全面が水になる。魚は全幅を泳ぎ、読む列の斥力は切る
- カーソルを追わない。魚は**逃げる**だけ（2.5 秒静止で警戒を解く）
- `prefers-reduced-motion`: 静止した1フレームだけ描く。WebGL 不可: `bg` の無地

## 組版

- 本文・見出しとも Noto Sans JP。日本語主体、英語は固有名詞と名前だけ
- `display`（Archivo 太字）は名前などごく少数の英字に限定
- `label`（JetBrains Mono 小）は日付・年・技術名・ステータス行に
- 表の項目名は 作品名 / 年 / 担当 / 技術。数えは「件」
- **大文字トラッキングの英語ラベルを乱発しない。巨大タイポ（10vw 級）禁止**

## 装飾の上限（DOM 側）

- 罫線は 1px の横罫だけ。二重罫・枠箱・通し番号・sticky の飾りは使わない
- 演出は `FadeIn`（そっと現れる）1種類と、ステータス行の時計だけ
- ホバーは「色が cyan になる」程度。動かさない
- 動きを足したくなったら、それは WebGL の水槽の仕事かを先に疑う

## 可読性の基準（実測必須）

- 本文（16px 以上）7:1 / 大きい文字 4.5:1
- 12〜14px の添字（`label`・日付・タグ・表の担当欄）は **4.5〜7:1 を許容**。
  faint の階層色は素の背景でも 7:1 に届かない設計で、7:1 まで上げると
  本文と明度が並んで階層が消える（DECISIONS 2026-07 の判断を継続）
- 計測は `scripts/verify/contrast.mjs`（描画画素で測る。背景は reduced-motion の
  静止フレームで測定される——動きの中の一瞬の重なりまでは保証しない設計）
- `prefers-reduced-motion`: FadeIn は即表示、時計と静止した水槽以外に動くものはない
