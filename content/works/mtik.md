大量のチケットを持っていると、申込・抽選・入金・発券・開催日・参加後の記録が、それぞれ別の場所に散らばってしまう。
mtik は、それを1つのアプリにまとめて「見失わない」ことを目指したアプリです。

## つくった理由

チケットの管理は、表計算ソフトでもメモアプリでもできます。
ただ、どちらも「次に何をすればいいか」を教えてはくれません。

入金期限が明日なのか来月なのか、抽選結果はもう出ているのか。
その判断を毎回自分の頭でやっていたので、アプリ側に持たせることにしました。

## つくったもの

- チケットの登録・一覧・検索・絞り込み・詳細確認
- 抽選発表日、入金期限、発券日、開催日などの状態管理
- カレンダーと WBS 的なタイムライン表示
- イベント画像を中心にしたジャケット型の一覧 UI

## 構成

`frontend/` に Flutter アプリ、`backend/` にサードパーティ API のキーを隠すためのプロキシを置いています。
API キーをアプリに埋め込まずに済ませたかったので、間に1枚挟む構成にしました。
